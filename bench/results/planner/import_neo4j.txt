# Import Neo4j: plan instrukcji krawędzi REGISTERED_IN - 10000 studentów
# init_db.py importuje węzły i krawędzie w jednej transakcji: przy planowaniu krawędzi węzły
# nie są jeszcze zatwierdzone, więc planista widzi statystyki pustej bazy (Estimated Rows = 0).
# Plany A-C w transakcji importu (węzły zaimportowane, niezatwierdzone), plan D po zatwierdzeniu.

pełna instrukcja (wariant C):
LOAD CSV WITH HEADERS FROM "file:///edges/student_registered.csv" AS row
MATCH (st:Person:Student {idx: row.student_idx}) USING INDEX st:Person(idx)
MATCH (g:Group {id: row.group_id})
MERGE (st)-[r:REGISTERED_IN]->(g)
SET r.registered_at = datetime(row.registered_at)
// Optional grade column; an empty or missing value leaves a grade set later through the API.
FOREACH (_ IN CASE WHEN coalesce(row.grade, "") <> "" THEN [1] ELSE [] END |
  SET r.grade = toFloat(row.grade)
)
