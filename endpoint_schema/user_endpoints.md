# Public and catalogue endpoints

Conventions used in all endpoint files:

- `X?` means the field is optional or nullable. `List[X]` is a JSON array.
- `Time` and `DateTime` values carry a UTC offset, e.g. `08:00:00+01:00`.
- Every endpoint except `POST /login` needs an `Authorization: Bearer <token>` header. `$student_idx`, `$teacher_idx` and similar "caller" parameters come from that token, not from the request.
- `$id` parameters in `CREATE` queries are UUIDs generated by the server.
- Create/update endpoints report failures in an `err` field instead of an HTTP error.

---

## POST /login

**Allowed:** anyone (no token required)

**Request**

```json
{
	"email": String,
	"password": String
}
```

**Response**

```json
{
	"ok": Boolean,
	"err": String?,
	"email": String?,
	"idx": String?,
	"roles": List["Admin" | "Teacher" | "Student"],
	"token": String?
}
```

Login fails if the password is wrong, the account has the `Inactive` label, or the person has no role.

**Query**

```cypher
MATCH (u:User {email: $email})
RETURN
  u.passwd_hash AS passwd_hash,
  u.email AS email,
  u.idx AS idx,
  u:Inactive AS inactive,
  u:Admin AS admin,
  u:Teacher AS teacher,
  u:Student AS student
```

## GET /teachers

**Allowed:** Student, Teacher, Admin

**Request**

Query string:

```json
{
	"name": String?
}
```

**Response**

```json
{
	"teachers": List[Teacher]

	Teacher = {
		"idx": String,
		"name": String,
		"surname": String,
		"phone": String,
		"degree": String,
		"photo": String?,
		"working_since": Date,
		"faculty": String
	}
}
```

**Query**

```cypher
MATCH (t:Teacher)
WHERE $name IS NULL
   OR toLower(t.name + " " + t.surname) CONTAINS toLower($name)
OPTIONAL MATCH (t)-[:WORKS_AT]->(fa:Faculty)
RETURN
  t.idx AS idx,
  t.name AS name,
  t.surname AS surname,
  t.phone AS phone,
  t.degree AS degree,
  t.photo AS photo,
  t.working_since AS working_since,
  fa.name AS faculty
ORDER BY t.surname, t.name
```

## GET /subjects

**Allowed:** Student, Teacher, Admin

**Request**

Query string:

```json
{
	"name": String?,
	"code": String?
}
```

**Response**

```json
{
	"cycle_columns": List[String],
	"subjects": List[SubjectCatalogueItem]

	SubjectCatalogueItem = {
		"code": String,
		"name": String,
		"ects": Integer?,
		"faculty": String,
		"cycles": List[SubjectCycleCell]
	}

	SubjectCycleCell = {
		"offered": Boolean,
		"group_count": Integer,
		"registration_open": Boolean
	}
}
```

`cycles[i]` belongs to the cycle named in `cycle_columns[i]`. Columns are in chronological order (`Z` before `L` within a year). A subject is offered in a cycle when some curriculum term taught in that cycle includes it.

**Query**

The server runs four queries and builds the grid from them. `$codes` is the list of subject codes returned by query 2.

```cypher
// 1. Columns: all academic cycles (sorted by the server)
MATCH (ac:AcademicCycle)
RETURN ac.id AS id, ac.year AS year, ac.season AS season

// 2. Matching subjects with their faculties
MATCH (su:Subject)
WHERE ($name IS NULL OR toLower(su.name) CONTAINS toLower($name))
  AND ($code IS NULL OR toLower(su.code) CONTAINS toLower($code))
RETURN
  su.code AS code,
  su.name AS name,
  su.ects AS ects,
  COLLECT {
    MATCH (su)<-[:INCLUDES]-(:CurriculumTerm)<-[:HAS_TERM]-(:Curriculum)<-[:HAS_CURRICULUM]-(:Programme)-[:OFFERED_BY]->(fa:Faculty)
    RETURN DISTINCT fa.name
  } AS faculties
ORDER BY su.name

// 3. Cycles each subject is offered in
MATCH (su:Subject)<-[:INCLUDES]-(:CurriculumTerm)-[:TAUGHT_IN]->(ac:AcademicCycle)
WHERE su.code IN $codes
RETURN DISTINCT su.code AS subject, ac.id AS cycle

// 4. Groups per subject and cycle
MATCH (su:Subject)<-[:INSTANCE_OF]-(si:SubjectInstance)-[:OFFERED_IN]->(ac:AcademicCycle)
MATCH (si)-[:HAS_TYPE]->(:GroupType)<-[:OF_TYPE]-(g:Group)
WHERE su.code IN $codes
RETURN
  su.code AS subject,
  ac.id AS cycle,
  count(g) AS group_count,
  sum(CASE WHEN EXISTS { (:Registration)-[:OPENS]->(g) } THEN 1 ELSE 0 END) > 0 AS registration_open
```

## GET /organizational-units

**Allowed:** Student, Teacher, Admin

**Request**

Query string:

```json
{
	"name": String?
}
```

**Response**

```json
{
	"faculties": List[Faculty]

	Faculty = {
		"id": String,
		"name": String,
		"full_name": String
	}
}
```

**Query**

```cypher
MATCH (fa:Faculty)
WHERE $name IS NULL
   OR toLower(fa.name) CONTAINS toLower($name)
   OR toLower(fa.full_name) CONTAINS toLower($name)
RETURN fa.id AS id, fa.name AS name, fa.full_name AS full_name
ORDER BY fa.name
```

## GET /curricula

**Allowed:** Student, Teacher, Admin

**Request**

Query string:

```json
{
	"name": String?
}
```

**Response**

```json
{
	"curricula": List[Curriculum]

	Curriculum = {
		"id": String,
		"programme_id": String,
		"name": String,
		"intake_year": String
	}
}
```

**Query**

```cypher
MATCH (p:Programme)-[:HAS_CURRICULUM]->(c:Curriculum)
WHERE ($name IS NULL OR toLower(p.name) CONTAINS toLower($name))
RETURN
  c.id AS id,
  p.id AS programme_id,
  p.name AS name,
  c.intake_year AS intake_year
ORDER BY p.name, c.intake_year DESC
```

## POST /subjects/detail

**Allowed:** Student, Teacher, Admin

**Request**

```json
{
	"code": String
}
```

**Response**

```json
{
	"code": String,
	"name": String,
	"ects": Integer?,
	"taught_by": List[TeacherName],
	"offerings": List[SubjectOffering]

	TeacherName = {
		"id": String,
		"name": String
	}

	SubjectOffering = {
		"cycle_id": String,
		"cycle": String,
		"group_count": Integer
	}
}
```

Returns 404 if the subject does not exist. `offerings` are in chronological order.

**Query**

```cypher
// 1. Subject and everyone who teaches any of its groups
MATCH (s:Subject {code: $code})
RETURN
  s.code AS code,
  s.name AS name,
  s.ects AS ects,
  COLLECT {
    MATCH (s)<-[:INSTANCE_OF]-(:SubjectInstance)-[:HAS_TYPE]->(:GroupType)<-[:OF_TYPE]-(:Group)<-[:TEACHES]-(t:Teacher)
    RETURN DISTINCT {id: t.idx, name: t.name + " " + t.surname}
  } AS taught_by

// 2. Cycles the subject is offered in, with group counts (sorted by the server)
MATCH (s:Subject {code: $code})<-[:INCLUDES]-(:CurriculumTerm)-[:TAUGHT_IN]->(ac:AcademicCycle)
WITH DISTINCT s, ac
RETURN
  ac.id AS cycle_id,
  ac.year AS cycle_year,
  ac.season AS cycle_season,
  COUNT {
    (s)<-[:INSTANCE_OF]-(si:SubjectInstance)-[:OFFERED_IN]->(ac),
    (si)-[:HAS_TYPE]->(:GroupType)<-[:OF_TYPE]-(:Group)
  } AS group_count
```

## POST /subjects/groups

**Allowed:** Student, Teacher, Admin

**Request**

```json
{
	"subject_code": String,
	"cycle_id": String
}
```

**Response**

```json
{
	"name": String,
	"subject_code": String,
	"cycle_id": String,
	"cycle": String,
	"groups": List[GroupTracked]

	GroupTracked = {
		"id": String,
		"weekday": Integer,
		"g_type": String,
		"number": Integer,
		"pnp": String,
		"capacity": Integer,
		"start_hr": Time,
		"end_time": Time,
		"cycle": String,
		"room": String,
		"filled": Integer
	}
}
```

Returns 404 if the subject has no groups in that cycle.

**Query**

```cypher
MATCH (su:Subject {code: $subject_code})<-[:INSTANCE_OF]-(si:SubjectInstance)-[:OFFERED_IN]->(ac:AcademicCycle {id: $cycle_id})
MATCH (si)-[:HAS_TYPE]->(gt:GroupType)<-[:OF_TYPE]-(g:Group)
OPTIONAL MATCH (g)-[:IN_ROOM]->(r:Room)
RETURN
  su.name AS subject_name,
  su.code AS subject_code,
  ac.id AS cycle_id,
  ac.year AS cycle_year,
  ac.season AS cycle_season,
  g.id AS id,
  g.weekday AS weekday,
  gt.g_type AS g_type,
  g.number AS number,
  g.pnp AS pnp,
  g.capacity AS capacity,
  g.start_hr AS start_hr,
  g.end_time AS end_time,
  r.building AS building,
  r.room_num AS room_num,
  COUNT { (g)<-[:REGISTERED_IN]-(:Student) } AS filled
ORDER BY gt.g_type, g.weekday, g.start_hr, g.number
```

## POST /groups/detail

**Allowed:** Student, Teacher, Admin

**Request**

```json
{
	"group_id": String
}
```

**Response**

```json
{
	"subject_code": String,
	"course_name": String,
	"g_type": String,
	"academic_cycle": String,
	"group_num": Integer,
	"weekday": Integer?,
	"pnp": String,
	"start_hr": Time?,
	"end_time": Time?,
	"room": String,
	"building": String,
	"nearest_classes": List[ClassOccurrence],
	"filled": Integer,
	"capacity": Integer,
	"teachers": List[TeacherName]

	ClassOccurrence = {
		"class_date": Date,
		"class_start": Time,
		"class_end": Time,
		"building": String
	}

	TeacherName = {
		"id": String,
		"name": String
	}
}
```

Returns 404 if the group does not exist. `nearest_classes` is always empty for now.

**Query**

```cypher
MATCH (g:Group {id: $group_id})-[:OF_TYPE]->(gt:GroupType)<-[:HAS_TYPE]-(si:SubjectInstance)
MATCH (si)-[:INSTANCE_OF]->(su:Subject)
MATCH (si)-[:OFFERED_IN]->(ac:AcademicCycle)
OPTIONAL MATCH (g)-[:IN_ROOM]->(r:Room)
RETURN
  su.code AS subject_code,
  su.name AS course_name,
  gt.g_type AS g_type,
  g.number AS group_num,
  g.weekday AS weekday,
  g.pnp AS pnp,
  g.start_hr AS start_hr,
  g.end_time AS end_time,
  g.capacity AS capacity,
  r.building AS building,
  r.room_num AS room_num,
  ac.year AS cycle_year,
  ac.season AS cycle_season,
  COUNT { (g)<-[:REGISTERED_IN]-(:Student) } AS filled,
  COLLECT {
    MATCH (t:Teacher)-[:TEACHES]->(g)
    RETURN {id: t.idx, name: t.name + " " + t.surname}
  } AS teachers
```

## POST /opinions/list

**Allowed:** Student, Teacher, Admin

Opinions are anonymous: the author is never returned. At least one of `teacher_idx` and `group_id` is required (HTTP 400 otherwise).

**Request**

```json
{
	"teacher_idx": String?,
	"group_id": String?
}
```

**Response**

```json
{
	"opinions": List[Opinion],
	"avg_grade": Float?

	Opinion = {
		"id": String,
		"grade": Float,
		"content": String?,
		"submit": DateTime,
		"group_id": String,
		"course_code": String,
		"course_name": String,
		"g_type": String,
		"cycle": String,
		"teacher_idx": String,
		"teacher": String
	}
}
```

**Query**

```cypher
MATCH (o:Opinion)-[:ABOUT]->(g:Group), (o)-[:ABOUT_TEACHER]->(t:Teacher)
WHERE ($teacher_idx IS NULL OR t.idx = $teacher_idx)
  AND ($group_id IS NULL OR g.id = $group_id)
MATCH (g)-[:OF_TYPE]->(gt:GroupType)<-[:HAS_TYPE]-(si:SubjectInstance)-[:INSTANCE_OF]->(su:Subject)
MATCH (si)-[:OFFERED_IN]->(ac:AcademicCycle)
RETURN o.id AS id, o.grade AS grade, o.content AS content, o.submit AS submit,
  g.id AS group_id, su.code AS course_code, su.name AS course_name, gt.g_type AS g_type,
  ac.year + " " + ac.season AS cycle, t.idx AS teacher_idx, t.name + " " + t.surname AS teacher
ORDER BY o.submit DESC
```
